# SpecFix

[![Build](https://github.com/Nip0s/cs2-SpecFix/actions/workflows/build.yml/badge.svg)](https://github.com/Nip0s/cs2-SpecFix/actions/workflows/build.yml)

Плагин [CounterStrikeSharp](https://docs.cssharp.dev/) для CS2, который убирает «фантомное тело» в режиме наблюдателя.

Когда живой игрок уходит в спектаторы, CS2 оставляет его старое тело как невидимый труп. При переключении камеры можно «залипнуть» на этом трупе. SpecFix перехватывает переключение так, чтобы камера **никогда не вставала на фантомное тело**.

## Возможности

- Пропускает фантома при листании целей ЛКМ/ПКМ (`spec_next` / `spec_prev`) — без мерцания, глюка HUD и залипания.
- Подстраховка для свободной камеры (`spec_mode`): если движок всё же навёл камеру на твоё старое тело, она сразу перекидывается на живого игрока.
- **Фикс «призрака» при смерти.** Если после смерти (или ухода в spectator/no-team) старое тело игрока всё ещё живое и функциональное — то есть человек мог бы продолжать ходить и стрелять, будучи формально мёртвым — плагин добивает это тело и сразу переключает камеру игрока на живую цель, а не оставляет его «призраком». Проверяется как сразу после `EventPlayerDeath`, так и каждый тик как подстраховка (на случай, если чистое событие смерти не сработало, например при абузе быстрого переключения команд).
- **Безопасно.** Не использует `Remove()`, не подменяет хэндлы, не телепортирует игрока — возврат за команду не крашит. Меняется только цель наблюдателя.
- Команда для включения/выключения на лету.
- Настраивается и локализуется.

## Требования

- Сервер CS2 с [Metamod:Source](https://www.sourcemm.net/)
- [CounterStrikeSharp](https://github.com/roflmuffin/CounterStrikeSharp)

## Установка

1. Скачай архив из [Releases](https://github.com/Nip0s/cs2-SpecFix/releases).
2. Распакуй содержимое в `game/csgo/addons/counterstrikesharp/` (папки `plugins` и `configs` встанут на свои места).
3. Перезапусти сервер

## Настройка

Конфиг: `addons/counterstrikesharp/configs/plugins/SpecFix/SpecFix.json`

| Параметр | Тип | По умолч. | Описание |
| --- | --- | --- | --- |
| `Enabled` | bool | `true` | Включить/выключить плагин. |
| `DebugLog` | bool | `true` | Писать в консоль при переносе камеры с фантома. |
| `FixGhostOnDeath` | bool | `true` | Добивать функциональное тело после смерти/ухода в spectator и переключать камеру на живую цель. |

## Команды

| Команда | Права | Описание |
| --- | --- | --- |
| `css_specfix [on\|off]` | `@css/generic` | Вкл/выкл. Без аргумента — переключает состояние. |

## Сборка

```bash
dotnet build -c Release
```

Готовый бандл: `bin/Release/net8.0/bundle/`.

CI (`.github/workflows/build.yml`) собирает плагин на каждый push/PR в `main`, кладёт `.dll`/`.pdb` и готовый бандл в артефакты сборки. При пуше тега `v*` (например `v3.5.0`) дополнительно зипует бандл и прикладывает его к GitHub Release.
